Component overhead — React 18.3.1

Two arms, one page, one DOM. Arm A writes the row's seven elements directly; arm B wraps each one in a pass-through component. Same data, same markup, same 10 000 nodes — so the delta is the component boundary and nothing else. A control compares the node census of both arms and refuses to report a per-instance figure if they differ.

No JSX and no build step on purpose: React.createElement is exactly what JSX compiles to, so this measures the same path a real app takes.
