# @symbiote-native/sms

## 0.1.0

### Minor Changes

- 80ed828: Add `@symbiote-native/sms` — a framework-agnostic wrapper around `expo-sms` (built on
  `expo-modules-core`, never the `expo` meta-package), reachable identically from React, Vue, and
  Angular. Opens the system SMS composer with recipients, message text, and optional attachments
  filled in: `sendSMSAsync` and `isAvailableAsync`.

  Nothing is sent on the user's behalf — both platforms hand the draft to their own composer and
  the user presses send. `sendSMSAsync` resolves once it closes, with `sent` or `cancelled` on iOS
  and always `unknown` on Android, which cannot report the outcome without the `READ_SMS`
  permission Google restricts to default-SMS-app publishers.

  A single recipient may be passed as a bare string and a single attachment as a bare object; both
  are normalised into the arrays the native side decodes. Android carries only the first
  attachment — its composer intent has one `EXTRA_STREAM` slot — so the extras are dropped before
  the native call rather than disappearing silently deeper down.

  Both adapter entry points are plain re-exports of the core: the two exports are stateless free
  functions with no per-instance state and no event stream, so there is nothing for a hook,
  composable, or service to wrap — the same shape `@symbiote-native/secure-store` has.

  The lightest native footprint of the Expo wrappers so far: no runtime permission on either
  platform, no `Info.plist` usage-description key, no manifest edit (`expo-sms` ships its own
  `<queries>` block, which merges in once the Gradle project is included), and no config plugin at
  all upstream. Android registration is generated by `@symbiote-native/expo-modules-link` from the
  package's `native-link.json`.

### Patch Changes

- 80ed828: Stop publishing co-located test files. These packages ship `src/` because the Angular entry's
  `default` export condition resolves back into it, which also swept in every `*.test.ts` beside
  those sources — 24% of tracking-transparency's unpacked size, 11% of web-browser's. `files` now
  excludes the `.test.`/`.spec.`/`.detox.` suffixes, and an eslint rule keeps them out.
- Updated dependencies [80ed828]
