`@symbiote-native/reanimated` carries the whole export list of react-native-reanimated 4.7.1 and react-native-worklets 0.13 for Vue, Svelte, Solid and Angular, next to React. Each adapter has the same hooks, `Animated` components, layout animations and CSS animation callbacks.
