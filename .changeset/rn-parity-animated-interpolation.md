`Animated` interpolation sends RN's native config: `deg` and `rad` output values become radians, colors become processed numbers with `outputType: 'color'`, and a `PlatformColor` range is marked `platform_color`. A `PlatformColor` output range now interpolates to the closest color and warns, as in RN. Output strings with different non-numeric parts (`20deg` and `30rad`) throw when the interpolation is created. `new Animated.Value(0, { useNativeDriver: true })` makes the value native, `stopAnimation(cb)` on a native value hands `cb` the value native holds, and detaching a native value saves it first. Animated values nested in plain objects and arrays inside any prop (not only `style`) are tracked and rasterized. `Animated.event` maps any argument and any shape of the event (`event([null, { state: { foo: value } }])`, `AnimatedValueXY`), not just `nativeEvent` of the first argument; the native driver still takes `nativeEvent` of the first argument only. `Animated.timing`, `spring` and `decay` accept `AnimatedValueXY` and `AnimatedColor` and animate each channel, so a vector can track another vector. Starting any animation stops tracking. `AnimatedColor` takes and sets a `PlatformColor`, has `resetAnimation`, and a color change flushes bound props once. `AnimatedProps` takes an update callback. An animation without `useNativeDriver` warns, a JS-driven animation over a value already moved to native throws at `start()`, `JSON.stringify` of an animated node gives its value, and `translate: [x, y]` inside a transform tracks animated values in the array. `IAnimation.start` takes one object instead of five positional arguments. `Animated.event` checks the event against its mapping once in a dev build (`Event has less arguments than mapping`, `Bad mapping of event key ...`), warns without options or without `useNativeDriver`, and a native event outside `nativeEvent` throws on attach. A native `Animated.loop` over `decay` runs the iterations in native. Dev builds log a native style, transform or interpolation property the native animated module does not support. Every adapter's `Animated` now comes from one shared driver set and gains `Animated.Interpolation`, `Animated.Node`, `Animated.Event` and `Animated.attachNativeEvent`; the reduced-motion mock accepts `AnimatedValueXY` and `AnimatedColor`. `StyleSheet.flatten` returns `undefined` for a non-object and the same object for a single style, and overwriting a style preprocessor warns.
