Short, direct answers to "how do I do X" — each page is a lookup, not a
tutorial. For the concept behind an answer, follow the link into
[Learn](/docs/learn/react/) or [API](/docs/api/); for a full copyable app, see
[Examples](/docs/examples/).

## Available how-tos

- [Style a component](/docs/howtos/styling/) — `StyleSheet.create` vs a Vue SFC
  `<style>` block.
- [Animate a value](/docs/howtos/animations/) — `Animated.Value`, and when the
  native driver can take over from the JS one.
- [Handle press/change events](/docs/howtos/events/) — React callback props,
  Vue emits, Angular `@Output()`.
- [Two-way bind a value](/docs/howtos/two-way-binding/) — Vue `v-model`,
  Angular `[(value)]`.
- [Share content across surfaces](/docs/howtos/portals-and-tunnels/) —
  `createPortal`/`Teleport` vs `createTunnel`.
- [Write platform-specific code](/docs/howtos/platform-code/) — the
  `X.ios.ts`/`X.android.ts`/`X/shared.ts` folder convention.
- [Wrap a third-party native view](/docs/howtos/third-party-views/) — why the
  library's React component can't be reused, and what can.
- [Wire up an Expo native module](/docs/howtos/expo-native-module-setup/) — the
  one-time per-app native setup every `expo-modules-core` wrapper package
  (Sensors, Haptics, Clipboard, …) needs before it resolves at runtime.
- [Add a native splash screen](/docs/howtos/splash-screen/) — generate the native
  binary, wire it into the native project, then `hide()` it from JS.
- [Turn on diagnostic logging](/docs/howtos/debugging/) — `dlog`/`isDebug` and
  the `DEBUG` env var.
- [Refs and attachments in Svelte](/docs/howtos/svelte-refs-and-attachments/) —
  `bind:this` vs `{@attach}` for imperative access to a host node.
- [Catch render errors (Svelte, Solid)](/docs/howtos/error-boundaries/) —
  `<svelte:boundary>` and `<ErrorBoundary>`, a fallback, and `reset()`.
