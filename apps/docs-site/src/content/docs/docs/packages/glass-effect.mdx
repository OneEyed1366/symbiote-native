`@symbiote-native/glass-effect` wraps
[`expo-glass-effect`](https://docs.expo.dev/versions/latest/sdk/glass-effect/), the Liquid Glass
native views of iOS 26, so every SymbioteNative adapter can reach them, not just React. Off iOS
both components render a plain `View`.

| OS platform | Support             |
| ----------- | ------------------- |
| iOS         | live                |
| Android     | plain View fallback |

| Framework adapter | Support |
| ----------------- | ------- |
| React             | live    |
| Vue               | live    |
| Angular           | live    |
| Svelte            | live    |
| Solid             | live    |

## Installation

```sh
npm install @symbiote-native/glass-effect
```

Scaffolding or extending a SymbioteNative app? `npx @symbiote-native/cli new --glass-effect` (or
`add --glass-effect` in an existing app) installs and wires this for you.

<Aside type="danger" title="Native setup is required before first use">
  `expo-glass-effect`'s native code is discovered by `expo-modules-autolinking`. Follow [How to:
  wire up an Expo native module](/docs/howtos/expo-native-module-setup/) once per app first.
</Aside>

<Aside type="caution" title="Check availability first">
  Some iOS 26 betas lack the Liquid Glass API and crash. Call `isGlassEffectAPIAvailable()` before
  rendering `GlassView` or `GlassContainer`.
</Aside>

## Props

| Prop               | Notes                                                                    |
| ------------------ | ------------------------------------------------------------------------ |
| `glassEffectStyle` | `regular` (default), `clear`, `none`, or `{ style, animate, animationDuration }` |
| `tintColor`        | A color, a `PlatformColor` or a `DynamicColorIOS`                        |
| `isInteractive`    | Default false                                                            |
| `colorScheme`      | `auto` (default), `light`, `dark`                                        |
| `spacing`          | `GlassContainer` only, the distance at which glass views merge           |

Plus `style`, `testID`, `nativeID`, `onLayout` and the accessibility and responder props every View
takes.

<Aside type="caution" title="Angular and the app identifier">
  An Angular template spells the iOS native tag statically. If the host sets an
  `__expo_app_identifier__`, the components warn that the tag does not match instead of rendering.
</Aside>
