  `AppRegistry.setWrapperComponentProvider` is re-exported but currently ignored

  `Animated.FlatList`/`Animated.SectionList` have no Svelte wrapper yet. Wrapper

  too — see the [status page](/docs/project/status/) for the exact line.

The Svelte adapter drives the same native Fabric engine as React, Vue, Angular, and
Solid, through Svelte's own custom renderer API: `createRenderer` from
`svelte/renderer`. The API is experimental in Svelte itself and needs
`svelte >= 5.59.1`. Components are compiled with `experimental.customRenderer`,
and every node operation routes into `@symbiote-native/engine`'s mutation API.
Components are ordinary `.svelte` files. Nothing about authoring one is
adapter-specific beyond the prop/event shape below.

The compiler rejects the constructs that need a DOM: `bind:` on an element,
`on:`, `transition:`, `animate:`, `{@html}` and the `<svelte:window>`,
`<svelte:document>`, `<svelte:body>` and `<svelte:head>` elements.

_The `examples/svelte` canary — the same component surface and engine as the
React, Vue, Angular, and Solid canaries, driven through Svelte's custom renderer._

## Minimal component

```svelte
<!-- App.svelte -->
<script lang="ts">
  let count = $state(0);
</script>

<view class="root">
  <pressable onPress={() => (count += 1)}>
    <text class="label">Count is {count}</text>
  </pressable>
</view>

<style>
  .root {
    flex: 1;
    align-items: center;
    justify-content: center;
  }
  .label {
    font-size: 24px;
  }
</style>
```

`view`, `pressable`, and `text` are intrinsic tags — no import needed. Only a
composed component (`FlatList`, `SectionList`, `VirtualizedList`,
`VirtualizedSectionList`, `KeyboardAvoidingView`, …) still comes from
`@symbiote-native/svelte`.

A component's own `<style>` block is scoped by default, the same as real
Svelte — no CSS-file import needed here, though one still works identically.
`StyleSheet.create` works too if you'd rather keep style objects inline — see
the [Styling guide](/docs/learn/styling/) for both paths.

`@media`, `@container` and `var()` in the `<style>` block resolve on the device, so a class can follow the window, the color scheme or a variable.
See [Media queries and variables](/docs/learn/media-queries-and-vars/).

## Svelte contract

- every component event is a real camelCase **prop** — `onPress={onTap}`,
  `onLongPress={...}`, `onValueChange={...}`, `onLayout={...}` — not a `on:x`
  directive and not kebab-cased like Vue's templates;
- children arrive as a `children` prop typed `Snippet`, rendered internally
  via `{@render children?.()}` — Svelte 4's `<slot />` has no place here.
  A component that hands state back to its children (`Pressable`'s
  `pressed`) is consumed with a named `{#snippet children(state)}` block,
  Svelte's own twin of a scoped slot;
- `text-input` and `switch` are tags, so they take the explicit `value`/`onValueChange`
  pair, since `bind:` on an element is a compile error. The Slider wrapper accepts
  `bind:value` on top of that contract. `value = $bindable()` is the declaration a
  wrapper author reaches for to add the same sugar to their own controlled component;
- `bind:this` on an element is a compile error, so `{@attach fn}` is the way
  to reach a host node from app code. It is the one directive-shaped
  construct the Svelte compiler accepts on a component at all (`use:`,
  `class:` and `style:` are rejected there);
- `<svelte:boundary>` is a real, Svelte-exclusive error-boundary primitive
  among the five adapters today. Wrap a subtree and provide a `failed`
  snippet. A thrown child then tears down cleanly instead of leaving the app
  in a broken state;
- Metro needs `@symbiote-native/svelte/metro-svelte-transformer` wired as the
  Babel transformer for `.svelte` files, plus
  `resolver.unstable_conditionNames: ['svelte-custom-renderer', 'browser']`,
  and `compilerOptions.experimental.customRenderer` in `svelte.config.js`.
  Without the condition Metro resolves Svelte's default runtime, which has no
  `svelte/renderer`.

Read the exact API surface in the [Svelte API reference](/docs/api/svelte/).
